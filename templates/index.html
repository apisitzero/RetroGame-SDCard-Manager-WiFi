เชื่อมต่อเครื่อง ArkOS ผ่าน Wi-Fi

วิธีดู IP ของเครื่องเล่น ArkOS (R36S, RGB20S, RG351 ฯลฯ):

1. ต่อ Wi-Fi ที่เครื่องเล่น (ผ่าน USB Wi-Fi Dongle หรือ Wi-Fi ในตัว)

2. ในเมนูของเครื่อง เข้าไปที่ Options / Settings -> Network Info หรือ Wi-Fi

3. สังเกตตัวเลข IP เช่น 192.168.1.150 แล้วนำมากรอกด้านล่าง
